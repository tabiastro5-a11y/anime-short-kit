# 見せ場の撮り方（場面の型）

参考24本（563カット）を場面の種類ごとに分けて調べた結果を、次回からそのまま使える型にまとめたもの（2026-11-23）。
カットの設計（`story.ts` の SHOTS / CAMS）と演技（`cast.ts`）を書く前に、台本の見せ場をここの型に当てはめる。

## 1. 見せ場をつくる5つの道具（どの型もこの組み合わせ）
| 道具 | 参考での使い方（測った値） | このスタジオでの作り方 |
|---|---|---|
| **寄る** | 中くらいの絵から、言葉に向けて**加速しながら顔のアップへ**（+17→+26→+34→+51 %/秒）。決めの一語では**急ズーム**（+150〜200 %/秒を 0.3〜0.5 秒）や、**2〜3 コマで一気に寄るスナップ**（+54〜57 %）。寄りは言葉の頭に着地。 | `pushK(f, 開始f, rate, punch, n)`（story.ts）。rate ≒ ln(1+毎秒の寄り)/30。+50 %/秒 ≒ 0.0135、+20 %/秒 ≒ 0.006。急ズームは punch 0.03〜0.04・n 10〜14。着地は言葉の 0〜2 f 前。 |
| **変わる** | 表情・姿勢が**言葉と同時に**変わる（ずれ中央値 0 f、−2〜+2 f）。10 秒に約3〜4回、1つを 1.2〜2 秒保つ。例：「祝う→疑う目」、「笑顔→真顔」、「顔が紫に」。 | `expr` の切り替え（`lidAt` の swaps でまばたきに隠す）、`act`（決めポーズ・腕組み・指さし…）。 |
| **記号** | 汗のしずく（最多）、目が丸くなる・光る輪・空っぽの点、怒りマーク・赤／紫の顔・湯気、オーラと火花、きらめき、？、稲妻。 | fx カード（`toon.ts` の fxBurst / fxStars / fxPuff …）。**足りない**：汗・怒りマーク・湯気・オーラ・顔色の変化（下の「まだ無い部品」）。 |
| **角度** | 力・脅威・決意は**下から見上げる**（low＋tilt up。決意の目＝下から MCU）。弱さ・小ささ・俯瞰の説明は上から。怒り・混乱は**傾き 5〜10°**（全体では 2°以上の傾きは 12 %、つかみでは 19 %）。 | `dolly(pos, look)` の pos を対象の目より 0.6〜1.2 m 下げる。傾きは `roll`（0.09〜0.17 rad = 5〜10°）。 |
| **間（ま）** | 決めの絵は寄り切ってから**0.2〜1.5 秒保つ**（ただし完全に止めない：じわっと寄り続ける）。オチの最後は 0.2〜1.3 秒の保持。 | 着地後 rate を 0.002〜0.003 に落とす。保持中もまばたき・小さな揺れ。 |

**分かったこと（数字）**：顔のアップ（MCU+CU+ECU）は全体の 11 %しかないが、**反応の場面では 33 %**（MS 53 %）。見せ場は「ずっとアップ」ではなく、**中くらいの絵から寄っていって、言葉の瞬間だけ顔が大きくなる**作り。カメラが止まっているカットは無い（全カットで寄る・引く・振る・じわ寄りのどれか）。

## 2. 場面の型（台本の見せ場に当てはめる）
各型：**絵の大きさの流れ／カメラ／角度／演技／記号／音・間**。「→」は1カットの中の変化。

### A. つかみ（0〜3 秒）
- 大きさ：MS か差し込み（物の寄り）。0 フレーム目から絵ができていて、**カメラはもう動いている**（速い動き 41 %）。
- カメラ：0.5〜1 秒で次の絵へ回り込む／振る。2 秒以内に1回目の切り替え。
- 角度：傾き 2〜10° を入れてよい（つかみの 19 %）。
- 演技：最初の一語で顔がパッと変わる（「ブレーキを踏んだ」で歯を食いしばる）。
- 音：最初の言葉は 0.00 秒から。

### B. 人物の紹介・名乗り（「男の名は〜」「〜の主人だ」）
- 大きさ：MS（背景に**その人を表す物**：店・道具・家）→ 名前の言葉で MCU まで寄る。
- カメラ：ゆっくり寄り（+10〜20 %/秒）、名前／肩書きの語で少し加速。
- 角度：目の高さか、やや下から（自信のある人物）。
- 演技：**決めポーズ**（`act: kime`）か、自分の物を示す（`present`）。表情は自信（smile→grin）。
- 例：01_inamura shot 5（醤油屋の前で示す→決めポーズ）。

### C. 決意・覚悟（「だから〜した」「〜すると決めた」）★
- 大きさ：MS → **顔の MCU〜CU**（決意の語で着地）→ 次のカットで行動（手元・道具の差し込み）。
- カメラ：**加速する寄り**（+17→+51 %/秒）を決意の語に着地。または静かな保持から**スナップで寄る**（+55 %）。
- 角度：**下から見上げる**（tilt up）。光は顔の片側から強く、背景は暗め・ぼかし強め（cInf 14〜16）。
- 演技：目が細くなる（決意の目）／口を結ぶ。道具を持ち上げる（例：六分儀を掲げる、松明を掲げる）。
- 記号：きらめき、目の光、火の粉・オーラ（力の強さに応じて）。
- 音：寄りに合わせて低い音が膨らみ、着地で一拍の間（音楽を -3〜-6 dB 落とす）。
- 参考：226615 #17（決意の目・下から MCU）、6841622 #5（祝う→疑う目へ加速して顔の CU）。

### D. 驚き・発見（「〜だと気づいた」「なんと〜」）
- 大きさ：**反応の顔（MCU/CU）**を先に、発見した物は次のカット（差し込み）。または顔の横に物を浮かべる。
- カメラ：顔へ急ズーム（+150〜200 %/秒、0.3〜0.5 秒）／顔の横を抜けて物に回り込む（顔→物のパン +60 %）。
- 演技：目が丸くなる（shock）→ 1 拍おいて次の表情。
- 記号：汗のしずく、？、目が光る輪。
- 音：着地にヒット音。

### E. 異変・災害・崩壊（地震・津波・爆発）
- 大きさ：引き（WS/EWS）で規模を見せる ↔ 中くらいで人の反応、を交互に。
- カメラ：**揺れは毎フレーム向きが変わり 7 f で減衰**（KICKS）、ぶつかる瞬間に切る（カット・オン・インパクト）。煙・ほこり・閃光を切り替え（ワイプ）に使う。
- 角度：下から（壁・波が高く見える）、傾き 7〜15°。
- 演技：倒れる・しゃがむ・逃げる。表情は shock / pained。
- 音：低い地鳴り→衝撃で最大、直後に一瞬の静けさ。

### F. 怒り・対立（「怒鳴った」「〜しろ！」）
- 大きさ：MS（2人なら肩越し）→ 怒る語で MCU へスナップ。
- 角度：**下から＋傾き 7〜10°**（ダッチ）。
- 演技：眉が怒る→顔が赤（紫）に 3 フレームで変わる→湯気。
- 記号：怒りマーク、赤い顔、湯気、稲妻。
- 参考：1552296 #5（怒りの拍で +7°）、31083315 #8（顔が紫に、湯気）。

### G. 力・脅威の登場（強敵・権力者・兵）
- 大きさ：WS（数の多さ）→ MS。
- 角度：**下から見上げる**、左右対称の構図（玉座・門）。
- 演技：笑う（evil laugh）、腕組み、にやり。
- 記号：オーラ、逆光のシルエット。

### H. 説明（「というのも」「でも実は」の後）
- 大きさ：WS・MS・差し込み（物の寄り 22 %）。図解は**同じ世界の中で**（物が割れて中が見える等）。
- カメラ：横移動・引きで要素を順に見せる。説明中も人物を時々入れて反応させる。
- 演技：話し手を見る、うなずく、指さす。

### I. 逆転・成功（「うまくいった」「守られた」）
- 大きさ：中くらい → 引きへ（成果の全体）→ 喜ぶ顔（MCU）。
- カメラ：速い動き（42 %）、上昇（crane up）で開放感。
- 演技：バンザイ（`cheer`）、決めポーズ、目を閉じた笑顔。
- 記号：きらめき、紙吹雪・花火。

### J. オチ・余韻（最後の 2 カット）
- 大きさ：WS / MS（引きか中くらいが 76 %）。最初の絵と**対になる絵**（同じ場所・同じ構図で状況が逆）。
- カメラ：ゆっくり引く or じわ寄り（33 %）。最後の言葉のあと 0.2〜1.3 秒保持して終わる（暗転・エンドカードなし）。
- 演技：静かな笑顔／振り返る。最後の一語で小さく動く。

### K. 真顔の反応（とぼけ・皮肉の一言）
- 大きさ：MCU（正面、真ん中）。
- カメラ：ほぼ止める（じわ寄り）。言葉の後に 1 拍。
- 演技：表情が「笑顔→真顔」に一瞬で落ちる。目だけ横に動く。

## 3. 1本を作るときの手順（チェックリスト）
1. 台本の文ごとに、上の A〜K のどれかを書く（`story.ts` の SHOTS のコメントに型の記号を付ける。例 `// C 決意`）。
2. **見せ場を3〜5か所**選ぶ（つかみ・紹介・決意・最大の異変・オチは必ず入る）。そこは型どおりに「寄る＋変わる＋記号＋角度＋間」を全部使う。
3. 主人公が**2秒以上、表情も姿勢も変わらずに立っているカットを作らない**（10 秒に3〜4回の変化）。
4. 顔の MCU〜CU を **10〜15 秒に1回**以上（反応・決意・オチで）。
5. 記号の数を数える（きらめき・オーラは1本に1回、同じ記号を続けない）。
6. 静止画で確かめる：見せ場のフレーム（着地の言葉の 0 f と +15 f）を必ず出して、顔の大きさ・角度・記号を見る。
7. 全フレームの確認（short_qa）のあとに、表情の変わる回数と顔のアップの割合を数えて、上の数字と比べる。

## 4. 部品（01_inamura で作成・使用。`templates/japan/` に入っている）
| 道具 | 部品 | 書き方 |
|---|---|---|
| 寄る | `landPush(f, f0, fLand, k1, creep?)`（story.ts） | f0 から加速して fLand（言葉のフレーム）に着地、その後じわ寄り。k1 0.4〜0.6（2〜2.5倍に寄る）。例 `dolly(pos, look, landPush(f, 731, 748, 0.42))` |
| 角度 | dolly の pos を顔より 0.6〜1.1 m 低く、look は顔か少し下 | 下から見上げる。傾きは `roll` 0.03〜0.13 |
| 変わる・表情 | `expr`：`determined`（決意）`suspicious`（疑い）`angry`（怒り）`scared`（おびえ）`smirk`（にやり）`empty`（空っぽ）`proud`（得意）＋既存14種 | 言葉の 2 f 前に切り替え（`LEAD`） |
| 変わる・ポーズ | `act`：`kime` `present` `armsCrossed` `cheer` `think`、作業の動き（parts.md） | k を 0.2〜0.3 秒で 0→1 |
| 記号 | `sym`：`sweat` `anger` `steam` `question` `exclaim` `sparkle` `aura`、`symT` で動かす | 頭に付いて動く。`aura` は体の後ろ |

**記号の使いすぎ禁止（ユーザーの決まり）**：同じ記号が何度も出ると安っぽい。**きらめき・オーラは1本に1回まで**（一番の見せ場＝ふつうは決意 C に使う）。汗・？・！も同じ人に続けて出さない。場面に合う記号を選び、合うものが無ければ記号なし（表情と寄りだけ）で決める。
| 顔色 | `flush`：赤 `#e8735a`（怒り）、紫 `#9a6ab8`（激怒）、白 `#e8eef0`（青ざめ） | 3 フレームで切り替え |
- 確認用の絵：`FaceSheet`（表情・記号・顔色）、`WorkSheet`（ポーズ・作業）。

### 字幕と顔の重なり（01_inamura で直した）
字幕は高さ約 70 %。顔のアップでは**顔の中心を高さ 35〜55 %**に置く（look を顔より少し下に向けると顔が上に上がる）。着地の絵は必ず静止画で字幕と顔が重なっていないか見る。

## 5. まだ無い部品
- カメラ：下から見上げる位置を対象から自動で出す関数（今は pos を手で決める）。
- 演技：お辞儀、頭をかく、泣く、走る（全力）の型。
- 記号：涙、汗の飛び散り、集中線（背景）。

### 夕方・朝の光で地面が水に見える（01_inamura で直した）
golden の影は青紫なので、太陽が海側（逆光、sunAz 0〜40）だと堤防の陸側と村の地面が影になって**水に見える**。陸を見せる引きの絵は太陽を背中側（sunAz 140〜170、sunEl 18〜22）にして地面を照らす。
