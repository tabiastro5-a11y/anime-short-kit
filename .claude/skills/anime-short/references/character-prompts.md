## いまの作り方：顔のない頭と体だけを作らせる
**作る前に、手持ちの人物（前に作った頭・服）で使い回せるものがないか探す。** 合わない人物だけを新しく作り、できたら表に1行足す。
AI に作らせるのは **顔の部品が1つもない頭（髪・帽子・耳だけ）と、体だけ**。目・眉・口・口ひげ・眼鏡・手足は Claude が
コードで描いて動かす（`src/lib/faceRig.ts`、決まりは `face-rig.md`）。AI の顔は表情ごとに色や形が変わり、画質も低かったため。
人物ごとに新しいチャットで、次の2通を1つずつ送る。作らせ方（Chrome の操作・保存・切り分け）は下の「作らせ方と切り分け」。

**1通目：頭（正面・真横・真後ろ）**
```
縦型ショートアニメの登場人物の「頭だけ」の部品を、1枚の画像に3つ並べて作ってください。
【絵のスタイル】2Dカートゥーン。塗りは平ら寄りで、なめらかな影を付ける。輪郭線は濃い紫がかった黒（#241726）で太く、上と左は細め、下と右下は約3倍太く。
手描きらしく、形は完全な円や左右対称にしない。光は左上から。文字・枠線なし。背景は透明（PNG）。
【大事な決まり】顔の部品は1つも描かない：目・眉・鼻・口・ひげ・しわ・ほお紅・眼鏡は無し。顔は肌の色だけで、右下にふちから内側へなめらかに暗くなる薄い影を付ける。
顔の部品は後から別に重ねます。顔の部分は広く、髪や帽子で隠しすぎない（顔の縦の6割以上が見えるように）。
【人物】〈例：コンビニの店員。20代の男性。濃い紺色の短い髪、前髪は眉の上で横に流す〉
【頭の形】〈例：横に少し広い丸（幅に対して高さ0.92）、あごに向かって少し細くなる〉。首は描かず、あごの下で切る。
【並べ方】左：正面。中央：真横（右を向く。耳が1つ見える。鼻の出っ張りは描かず、顔の前側はなめらかな丸み）。右：真後ろ（髪と耳だけ）。
3つとも同じ大きさ、同じ髪型、同じ線と塗り方。十分にあけて並べる。
```
**2通目：体（正面・真横・真後ろ）**
```
同じ人物の「胴だけ」の部品を、1枚の画像に3つ並べて作ってください。同じ絵のスタイル。
胴は縦長の豆（卵）の形で、上は細く、高さの6〜7割が一番太く、下は丸い。腰で終わる：下2割ほどをズボン（スカート）の色にして、そのまま丸く閉じる。
脚・足・靴は1本も描かない。頭・首・腕・手も描かない。袖・袖口・肩の線も描かない（腕は後から細い線で付けます）。
【服】〈例：黄色いベストに白いシャツ、胸に小さな名札（文字なし）、紺のズボン〉。細かい部分は5つまで、内側の線は輪郭の半分以下の細さ。
影は左から右へなめらかに暗くなり（右端は左の6割ほどの明るさ）、右のふちのすぐ内側に細い明るいふち。
【並べ方】左：正面。中央：真横（右を向く。正面より細い豆の形。服の前側が右）。右：真後ろ（背中側）。十分にあけて並べる。背景は透明（PNG）。
```
- 帽子を脱ぐことがある人物は、頭は帽子なしで作り、帽子だけ（正面・真横・真後ろ）を別の1通で作らせる。いつもかぶっている人物は頭に含める。
- 服を着替える人物は、2通目を服ごとに送る。
- 口ひげ・眼鏡・そばかすは作らせない（顔リグの `fix` で描く）。
- **真横の向きは必ず確かめる**（「右を向く」と頼んでも左向きで返ることがある）。逆なら左右反転する。
- 参考動画のコマは添付しない。

## ⑤ 横顔の一覧と横の口（必ず作る。1回ずつ）
**横顔は必ず作る**（2026-11-24 ユーザー：横向きで歩く場面に正面の顔が載るのは問題）。
```
設定画と同じ人物の「真横を向いた頭だけ」（右を向く横顔）の一覧表を1枚で作ってください。
・4列×3行の12マス。どのマスも同じ人物、同じ髪型（帽子や眼鏡があればそのまま）、同じ頭の形、同じ線と塗り方、同じ大きさと位置
・真横から見た形：目は1つ、鼻は小さく前に出る、耳は頭の中央あたりに1つ。首は描かず、あごの下で切る
・顔の影と線の太さは正面の顔の一覧と同じ
・口は描かない（口のあたりは肌色のまま。口は後から別に重ねます）。目と眉だけで表情を出す
・マスどうしは十分にあける。枠線や文字は入れない。背景は透明（PNG）
・並び順は正面の顔の一覧と同じ12種
```
```
同じ人物の「真横（右向き）から見た口だけ」の一覧表を1枚で作ってください。口以外は描かない。
・3列×2行の6マス、同じ縮尺・同じ線の太さ。マスの中央に置き、十分にあける。枠線や文字なし。背景は透明（PNG）
・口は顔の右のふちに付く形（右端が開いた形）で描く
・並び順：1 閉じた普通の口　2 にっこり　3 小さく開いた口（話す）　4 大きく開いた口（叫ぶ・笑う）　5 への字　6 歯を食いしばった口
```
**向きを必ず確かめる**：「右を向く」と頼んでも、真横の胴や帽子が左向きで返ることがある（調査員の胴と野球帽がそうだった）。
切り分けたあと、ボタン・ファスナー・つばが右側にあるかを見て、逆なら絵を左右反転する。
横の口には顔のふちの縦線が付いてくるので、切り分けのあと右側の縦線を切り落とす（口は右端を顔のふちに合わせて置く）。
組み込み：`cast.ts` の sprite に `side: [顔の中心x, y, 口の位置x, y, 閉じた口の幅]`（横顔の絵に対する割合）。

切り分け：`slice_character.py <名前> --sidefaces … --sidemouths …` → `<名前>_side_<表情>.png`、`<名前>_smouth_<形>.png`
（closed, smile, talk, shout, frown, teeth）。

## ⓪ 表情の描き方（参考動画のやり方。顔の一覧すべての頭に付ける。2026-11-24）
ユーザー：「表情の作り方は参考動画を参考に」。参考動画のコマを見直した結果、表情は**かわいい記号ではなく、目の形を極端に変えて**出している
（ふだんは半目の無表情 → 驚くと白い大きな丸に点の黒目 → 喜ぶと閉じた弧に歯の格子、など。落差が笑いになる）。
```
【表情の描き方】乾いた、とぼけたユーモアのカートゥーン。かわいい表現は使わない（＞＜の目、うるうるした大きな瞳、ハート、きらきらは禁止）。
基本は無表情に近い「半目」（上まぶたの平らな太い線と、その下の黒い半円）。感情は、目の形を極端に変えることで出す：
黒い点／縦長の黒い楕円／白い大きな丸（細い輪郭）に小さな黒目／閉じた∩の弧／ぎゅっと閉じた太い線／左右で大きさの違う目。
眉は太く短い棒で、必要な表情にだけ描く（片方だけ上げる、目にくっつけて斜めにする、など）。
記号は最小限（汗1つ、太い涙の筋、青い縦線、怒りマーク）で、必ず頭の輪郭の内側に描く。左右対称にしない。目のハイライト・ほっぺの赤みは無し。
```
口も同じ考え方：単純な形、歯は白い四角に縦の仕切り線、口の中は濃いえんじ色。
基本12種（②）もこの描き方で作る：1 普通（半目の無表情）　2 目を閉じた普通（平らな線2本）　3 にっこり（閉じた∩の弧）　4 大笑い（ぎゅっと閉じた太い線、眉が上がる）
5 驚き（白い大きな丸に小さな黒目、2つがほぼくっつく）　6 怒り（太い眉が目にくっついて内側に下がる）　7 ずる賢い（半目、片眉だけ高く）　8 焦り（小さな縦長の黒目、八の字眉、汗1つ）
9 おびえ（白い丸い目に点の黒目、おでこに青い縦線）　10 決意（鋭い半目、太い眉を水平に低く）　11 悲しい（外側が下がった半目、八の字眉）　12 ぼうぜん（黒い点2つだけ）
切り分け：`slice_character.py <名前> --faces 基本 --facesA A --facesB B --mouths 口1 --mouths2 口2`（A・B は基本と同じ頭の大きさにそろえる）。

## 作らせ方と切り分け（2026-11-24）
- **ChatGPT はユーザーの Chrome を Claude が操作して使う**（Claude in Chrome。月額プランの中で済む。API は高いので使わない）。
  人物ごとに新しいチャットで、設定画 → 顔 → 口 → 胴の順に1つずつ送る（別の人物は別のタブで並行できる）。
- 保存：Chrome は1つのタブで2回目からの自動保存を止める。**1つのチャットの画像を1つのファイルにまとめて1回で保存**する
  （ページの中で画像を集めて「長さ12桁＋中身」を並べた .bin にする → ダウンロード → こちらで分ける）。画面の外の画像は
  読み込まれていないので、上から下までスクロールしながら集める。保存の前にユーザーの「はい」をもらう。
- 切り分け：`python scripts/slice_character.py <名前> --faces … --mouths … --torso … [--torso2 … --suffix2 suit] [--back …]`
  （顔は頭の形でそろえて同じ大きさに、口はぴったりに、胴は左から 正面・真横・真後ろ・後ろ頭。2段目は帽子）。
- 組み込み：`cast.ts` の服に `sprite: { name, mouthX, mouthY, mouthW, mouthRef, headK, faceX, faceY, body: ""（別の服は "_suit"）, hat, hatW, hatY }`。
  胴の絵は `toon.ts` の bodyFront / bodySide が豆の胴の代わりに描く。横向きの頭の絵はないので、横向きでも正面の顔を使う。

## 置き場所とファイル名
`assets/characters/<名前>/` に、そのまま保存して置く（名前を付けなくてよい。Claude が切り分けて名前を付ける）。
`<名前>` は半角英字（例：clerk、agent、lady、cop）。Claude が作るファイル（`public/<回>/people/`）：
```
<名前>_head_<表情>.png   ② を切り分けたもの（neutral, blink, smile, laugh, shock, angry, smirk, nervous, scared, determined, sad, dazed）
<名前>_mouth_<形>.png    ③ を切り分けたもの（closed, smile, laugh, frown, talk_s, talk_m, shout, o, teeth, smirk, wavy, small）
<名前>_body_front.png / <名前>_body_side.png / <名前>_body_back.png / <名前>_head_back.png   ④ を切り分けたもの（胴は袖なしの豆の形）
```

## うまくいかない時
- 顔が設定画と変わった → 「設定画と同じ顔・同じ髪・同じ線の太さで作り直して」
- マスが重なった・大きさがばらばら → 「マスどうしをもっとあけて、全部同じ大きさで」
- 背景が白い → そのままでよい（Claude が切り抜く）
- 胴の絵に脚・足が入った → 「胴の絵は腰で終わりにして、脚と足は1本も描かないで。下の端はズボンの色のまま丸く閉じた、卵のような形だけ」
- 胴に袖や腕が描かれた → 「胴は袖なしの豆の形だけ。腕・袖・肩は描かないで」
- 輪郭線が均一 → 「線は上と左を細く、下と右下を3倍くらい太く」
