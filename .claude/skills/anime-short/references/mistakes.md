# よくある失敗（カットを作る前に毎回読む）

> **優先順位**：見た目・カメラ・音・確認は `cartoon-3d-short` スキル（Mr omi 氏）に従う。この資料と食い違う所は、そちらを優先する（2026-11-23）。


同じ種類の問題が2回出たらここに足す。書き方：何が起きたか（どの回・何回）／どう防ぐか。

1. **カメラが物の中に入る**（01_inamura の試作で3回：村人・民家の屋根・木）
   → 静止画の前に必ず `node scripts/shot_lint.mjs <名前>Lint out/<名前>/check/lint.md`（カメラのめり込み・向き・映り込み・抜けを点検）。物を動かすか、カメラを「上がってから進む」道筋にする。
2. **カメラが人物を追い越して、人物が画面から外れる**（参考の制作動画と、01_inamura カット1）
   → 人物が動くカットは、カメラ位置を人物からの相対位置で決める。
3. **板の中心で置いたせいで、炎や物が根元から浮く**（01_inamura の松明・稲むら）
   → 炎などの板は根元を原点にする（`Fire` は対応済み）。
4. **演技が見えない**：人物が遠い・画面の端にいる（01_inamura カット3）
   → 縦長の画面は横が狭い。演技を見せる人物は画面中央・カメラから2〜4mに置く。
5. **仕上げで線が消える／夜が暗すぎる／空が無地**（01_inamura v1・v2）
   → `visual-rules.md` の「色と線」。書き出し前に静止画を撮り、`scripts/look_check.py` で参考の範囲に入っているか確かめる。
