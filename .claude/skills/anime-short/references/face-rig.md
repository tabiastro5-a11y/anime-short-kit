# 顔の動かし方（参考動画を1コマずつ調べた結果と、顔リグの決まり）

2026-11-24 ユーザーの方針：
- AI に作らせるのは **顔の部品のない頭（髪・帽子だけ）と体だけ**。目・眉・口・手足は Claude がコードで描く
  （AI の顔は表情ごとに色や形が少し変わる、画質も低い）。
- 参考動画では **目は別の目に一瞬で替わる。眉と口は別々の部品として変形・移動する**。これを再現する。
- この動画専用にしない。**どの動画でも使える表情の仕組み**にして、テストと改善を繰り返す。
- 今のキャラクターの顔・服は前提にしない。

道具：`src/lib/faceRig.ts`（表情の一覧 `POSES`、動き `faceAt`、描画 `drawFace`）。試し場：全表情を並べる1枚のコンポジションと、演技の流れを見るコンポジションを作って確かめる
。調べたコマは手元だけに置く（Git に入れない）。

## 調べ方
参考動画（手元の勉強用、1080×1920・30fps）から顔の寄りを**1コマずつ**切り出して番号付きで並べる：
```
ffmpeg -i <動画> -vf "select=between(n\,A\,B),crop=560:560:X:Y,scale=200:200" -fps_mode passthrough x_%03d.png
```
まず8コマおきの一覧で場面を探し、顔の寄りの区間を1コマずつ見る。

## 分かったこと（元動画 VKsamN3Fk4U の f78–125、f120–179、f376–425）
### 目：種類は一瞬で替わる。必ず瞬きをはさむ
- 替わり方（f389→394、f398→405 など）：**今の目がつぶれる1コマ → 閉じた線2コマ → 新しい目がつぶれた形で1コマ → 新しい目（最初の2コマは少し大きい）**。
- ふつうの瞬きも同じ4コマ（f156–159：つぶれ1・閉じ2・開く）。
- 驚きの直後に「開く→閉じる→開く」を1回くり返すことがある（二度見。f398–404）。
- 目の種類：半目（上まぶたの太い横線＋下に濃い半円。ふだんはこれ）／黒い点／太い輪の丸い目（中は白、小さな黒目）／閉じた線／
  閉じた弧（喜び）。色は真っ黒ではなく濃い暖かい灰色、半円は上が濃く下が少し薄い。

### 眉：別の部品。出たり消えたりしながら、数コマかけて動く
- 太く短い先細りの線。半目だけの顔では眉が無いことも多い（まぶたの線が眉の役をする）。丸い目のときも眉なし。
- 動きは連続：位置・角度・反りが 4〜6 コマで変わる（f120–129、f150–156）。左右は別々（片方だけ上がる・下がる）。

### 口：1つの形が、幅・開き・反り・傾き・位置を変えていく
- 話すとき（f130–175）：閉じた線 → 太い横棒 → 歯の帯が見える横長 → 舌の見える大きな口、を**1〜3コマごと**に行き来する。
  開きの大きさは声の大きさに合っている。開くほど少し幅が狭くなる。
- 表情の口（f390–405）：にやりの口が4コマで大きくなり（歯の仕切り線つき）、いちど最大まで行ってから少し戻る。
  戻るときは小さく傾いた「片側のにやり」になり、顔の片側へ寄る。
- 驚きの口（f84–97）：丸い口が13コマかけて小さくなり、消えてから小さなにやりの線に変わる。
- 口は止まっていても、わずかに位置が動いている。

### そのほか
- 汗は1つ、こめかみを約1秒かけて滑り落ちて消える（f82–106）。
- 表情が替わる瞬間、顔全体がわずかに大きくなる。髪の房が遅れて揺れる。

### 口ひげ・眼鏡（元動画 f186–255：帽子の客）
- 口ひげは口とは別の部品。幅は顔の4割ほどの太いアーチで、両端が下がる。**口が開くと持ち上がって広がる**（口はひげの下に出る）。
- 帽子をかぶった人物は眉が無く、まぶたの太い線が眉の役をする。片方のまぶたの上に弧が出て「片眉を上げた」顔になる。
- 瞬きは f208–209、f227–228（どちらも閉じ2コマ）。話している間も目は半目のまま動かない。

## 顔リグの決まり（faceRig.ts）
- 単位は顔の幅 W の 1%（u）。原点は両目の間。目の間隔 33u、眉はまぶたの 13.5u 上、口は 19u 下（参考と並べて合わせた値）。
- 顔に付く物（`fix`）：口ひげ・眼鏡。人物ごとに色を渡す。口ひげは口の動きに付いていく。
- 表情は名前で選ぶ（`POSES`：neutral, deadpan, bored, shock, panic, smug, grin, greedy, cry, bawl, rage … 40種）。
  1つの表情＝目の種類（左右別も可）、眉2本（高さ・角度・反り・見えるか）、口（幅・開き・反り・傾き・位置・歯・舌・震え）、記号（汗・涙・青い縦線・怒り・よだれ）。
- 時間の流れは `faceAt(keys, f, {talks, amp})`：`keys`＝「何コマ目からどの表情か」、`talks`＝せりふの区間、`amp`＝声の大きさ（1コマごと）。
  - 目：上の「つぶれ1・閉じ2・つぶれ1・少し大きく2」で自動的に替える。瞬きは 1.5〜4 秒ごと、人物ごとにずらす。
  - 眉・口：5コマで行き過ぎてから戻る動き（`pop`）。
  - せりふ中の口は声の大きさで開く（線 → 歯の帯 → 舌）。表情の口は「休みの形」として残る。
- 新しい表情が要るときは `POSES` に1行足す（その動画のためだけの特別な描き方はしない）。

## これから（テストと改善）
- ほかの参考動画でも同じ調べ方をする（泣く・怒る・笑い転げる・横顔）。足りない目の種類・口の形を足す。
- 参考のコマと試し場のコマを並べて見比べ、動きの速さ・行き過ぎ・口の形を合わせる。
- 頭（髪・帽子だけ）と体の絵を作らせ、その上に顔リグを載せる。横顔用の目・口の置き方を作る。
- `toon.ts` の人物（頭の絵の上に顔を描く所）へ組み込む。

## 顔のない頭と体に載せる（2026-11-24 夜、最初の4人）
- ChatGPT で「顔の部品のない頭（正面・真横・真後ろ）」と「袖なしの豆形の胴（正面・真横・真後ろ）」を人物ごとに2通で作成。4人とも1回で通った（指示文は character-prompts.md の「いまの作り方」）。
- 置き場所：元の絵 `assets/characters/<名前>/`（Git に入れない）、切り分け `public/<回>/cast2/`（`cast2.json` に頭の絵の大きさと顔の範囲）。
- 顔の位置は絵から自動で出す：肌色の範囲を測り、目の高さ＝肌の範囲の上から 46%、顔の幅 W ＝肌の幅の約 0.98 倍（耳を含むので）。
- 横向きは `drawFaceSide`：目1つ・眉1本・幅を 55% にした口を顔の前側へ寄せる。口ひげ・眼鏡も横用の形で描く。
- 見本：人物ごとに正面・横を並べ、表情が順に替わるコンポジションを作って確かめる。
- 残り：`toon.ts` の人物（3D の場面のカード）への組み込み、後ろ姿、手足と体のつなぎ、表情の割り当ての書き直し。

## 体の等身と動き（元動画 f1000–1071 の待合室、f1150–1221 の歩いて入る場面を1〜3コマおきに確認）
- 等身：頭は胴と同じ幅か少し広い。胴は頭1個分ほど、脚は細い線で頭1.3個分、全体で約3.3〜3.5頭身。今の `toon.ts` の体の決まり（BUILD：胴1.1・脚1.4）と同じだったので、等身は変えていない。頭の絵は「顔の幅＝コードの頭の幅×headK（1.0〜1.28）」で載せる。
- 腕と脚：1本の細い濃い線。手は小さな丸。腕は肩の少し内側から出て、ひじは曲線で曲がる。万歳は手が頭より上（f1044〜）。
- 胴と頭の動き：
  - 退屈で**のけぞる**：胴が後ろへ約10°、頭はさらに約15°傾き、天井を見る。8コマほどかけて倒れ、そのまま止まる（f1004–1012）。
  - **起き上がりは速い**：5コマほどで戻り、最初の2コマは頭が少し上へ飛び出す（f1036–1044。予備動作）。
  - 止まっているあいだも、足や頭がわずかに動く（脚をぶらぶら、f1000–1006）。
  - 歩きは体が小さく上下し、腕は体の横で小さく振れる（f1150–1190）。
- 組み込み：待合室の「5分」で `tilt -9°・headTilt -15°`（8コマで倒れ、5コマで戻る）。

## 動画への組み込み（2026-11-24）
- `toon.ts`：`Sprite.rig` があれば `drawRigHead`（頭の絵＋ `drawFace` / `drawFaceSide`）。`FrontOpts.face` / `SideOpts.face` に顔を渡す。
- `cast.ts`：場面のコードは今までどおり「このコマの表情名」を書くだけ。`stage()` が前後のコマ（-10〜+3）を先に調べて表情の履歴を作り、
  `faceAt` で目の入れ替え・眉と口の動き・声に合わせた口を作る。`talk:` の付いた区間がせりふ。古い表情名は `POSE_OF` で新しい名前に読み替える。
- 部品は `public/<回>/cast2/`、顔の範囲は `cast2.json`、声の大きさは `amp.json`（voice.wav から1コマごと）。
- **テンプレートについて**：顔（`src/lib/faceRig.ts`）は共通部品にした。体の描き方（`toon.ts`）は動画フォルダごとのコピーのままなので、
  次の動画を始める前に `toon.ts` の人物部分を `src/lib/` に出して共通にするのがよい（未実施）。

- **等身は全員そろえる**（2026-11-24 ユーザー：おでこの広い男の頭が大きすぎた）。頭の絵は「絵全体の幅＝コードの頭の幅×1.45」で全員同じ、体格も全員 adult、胴の絵の高さも同じ。人物の違いは髪・服・顔の部品で出す（子どもなど別の等身が要るときだけ例外）。
