## カメラ
- **カット割り・つなぎ・画の大きさ・言葉との合わせ方は `shot-grammar.md`**（563カットの分析）。要点：**約2.2秒ごとに絵を切り替え、つなぎはクロスフェード（5フレーム）とカメラの移動が中心**、ハードカットは衝撃だけ。
- 常に動かす（参考：88%のフレームで動いている、静止は約5%）。前に進む（ズームイン）が64%。速さは1フレームで約0.3%拡大、横移動は画面の約0.5%。
- 区間の動きは「ゆっくり入ってゆっくり止まる」（`cam.ts` の `path`）。
- **人物が動くカットは、カメラの位置を人物からの相対位置で決める**（人物を追い越さない）。
- 縦長の画面は横幅が狭い（画角48°で3.5m先なら左右に約0.9m）。演技を見せたい人物は画面の中央にまとめる。
- 物の間を抜けるときは、まず上がってから進む。家並みや木の箱にカメラを通さない（`check.mjs` で確かめる）。
- 地震などの揺れは `shake()`。

## 人物
- 白くて丸い頭、点の目、太い黒の輪郭、細い棒の手足、服は平らな色。帽子や髪型で見分ける。光を受けて影を落とす（`Character`）。
- 和装：髪型 `chonmage` `nihongami` `tenugui`、服 `coatStyle: "kimono"`（襟・帯・広い袖）。松明は `torch: "R"`。
- **表情は型の名前で指定する**（`faces.ts` の `EXPRESSIONS`、27種類。一覧 `npm run gallery` → ExpressionSheet）。
- **動きは演技の型で指定する**（`acting.ts`、19種類：idle talk surprise realize panic cry laugh shout think nod look_around cheer relief determined shiver sigh walk walk_worried run）。
  `pose={{ ...perform([{ at: 0, act: "talk" }, { at: 1.6, act: "surprise" }, { at: 2.6, act: "panic" }], t, seed) }}`
- 同じ出来事でも、人ごとに違う反応の型を当てる（全員同じだと作り物に見える）。地震の前は「生活」の演技（話す・うなずく・歩く・笑う）を入れて、揺れの瞬間との差を出す。
- 新しい表情・演技が必要なら、カットに直接描かず `faces.ts` / `acting.ts` に型として足す。

## 色と線（仕上げ処理 `Post.tsx`）
- **線は色を整えたあと、最後に引く**（先に引くと黒の持ち上げで線が灰色になって消える）。線の色は真っ黒にしない（#0e0a16）。
- **空を無地にしない**：輪郭線のある雲（`Cloud`、夜は `tint` で青く）と、空の筆のむら（`Sky`）を入れる。上4分の1が無地だとくっきり度の比が跳ね上がる（17倍）。
- 夜でも暗くしすぎない。参考の夜は「青紫の夜」で、明るさは昼と大差ない：空 top #22358c / horizon #6d66c6、環境光（hemi）1.6、露出1.2〜1.25。
- 彩度は仕上げで上げすぎない（1.08倍）。影は青紫寄り、明るい部分はわずかに暖色。
- ぼかしは控えめ。**参考の98%のカットは「弱い」か「なし」**（強いのは接写の差し込みの3%だけ）。引きの絵はぼかしなし、中くらいは弱く（blur 2〜3.5）、接写だけ強く。手前のぼけは奥の半分以下。明るい所は柔らかく圧縮して白飛びさせない。
- 炎・雲・星・名札・しぶきは「人物の層」（`CHARACTER_LAYER`）に置き、線とぼかしの対象から外す。
- 光の流れ：明るい場面で始め、全体の40〜70%で夜の青に入り、最後に明るさが戻る（参考の平均）。
