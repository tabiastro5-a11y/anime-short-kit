# カットの文法（参考24本・563カットを1カットずつ分析、2026-11-23）

> **優先順位**：見た目・カメラ・音・確認は `cartoon-3d-short` スキル（Mr omi 氏）に従う。この資料と食い違う所は、そちらを優先する（2026-11-23）。


分析は4組の分析役がフレーム単位で行った。自動のカット検出（`measure.py`）はクロスフェードを見落とし、速い移動を誤検出するので、**カットの数には使わない**。

## 1. 絵の切り替えの速さ
| 項目 | 参考 |
|---|---|
| 1本のカット数 | 中央値24（16〜32） |
| 1分あたり | 約23カット |
| カットの長さ | 中央値 **2.2秒**（10%: 0.9秒、25%: 1.4秒、75%: 3.5秒、90%: 4.8秒）。最長でも約6〜8秒 |
| 1文あたり | 約1.35〜1.5カット |

- 長いカット（5〜6秒）は、説明の差し込み（図解）と最後のオチだけ。話している人物を長く映さない。
- **切り替えは文の切れ目ではなく、文の途中の「その絵を指す名詞」に置く**（文の頭に近いのは34%だけ。文と文の間の無音で切り替えるのは125回中5回）。

## 2. つなぎ方
| つなぎ | 割合 | 使いどころ |
|---|---|---|
| **クロスフェード** | 50% | 標準。中央値5フレーム（4〜8）。場所・時間・光が変わる所 |
| **カメラの移動でつなぐ** | 26% | 物の中・窓・穴・瞳を通り抜ける、地面から空へ上がる、看板から人物へ振る |
| ハードカット | 15% | 衝撃・叫び・オチの連打だけ。衝撃の瞬間ちょうどに切る |
| 素早く振る（ホイップ） | 4% | |
| 白フラッシュ | 1% | 画面内の光源（稲妻・爆発）から8〜15フレームで大きな時間の跳び |

## 3. カメラ
- **すべてのカットで動く**（止まっているカットは0。止まって見える所も、毎秒2〜5%でじわじわ寄る）。
- 動きの種類（1カットに複数あり）：寄る51%、横に振る24%、じわじわ寄る23%、引く22%、横移動11%、上下6%、上昇6%、回り込み4%。
- 速さ：ゆっくり31%、中31%、速い21%、じわじわ17%。速い動きは、つかみ・つなぎ・衝撃に使う。
- **急速ズーム**：オチの言葉で1秒あたり100〜200%の寄りを0.3〜0.5秒（「キック」）。寄りを段階的に速める（+17→+26→+34→+51%/秒）。
- 傾き（ダッチアングル）はほぼ使わない（2%）。例のスキルの「4〜5°の傾き」は、この参考には当てはまらない。

## 4. 画の作り
| 項目 | 参考 |
|---|---|
| 大きさ | 中くらい（MS）41%、引き（WS）27%、差し込み14%、大引き6%、寄り（MCU+CU+ECU）11% |
| カメラの高さ | 目の高さ67%、高い12%、低い12%、地面5%、真上3% |
| レンズ | 広角71%、標準27%、望遠2% |
| 配置 | 中央74% |
| **手前の小物** | **43%**（肩越しの頭、カウンターの縁、柱、車輪、瓦礫） |
| 背景のぼかし | 弱い61%、なし37%、**強い3%**（強いのは接写の差し込みだけ） |

- 寄りは、反応・感情の瞬間に、寄っていく動きの最後に使う。
- 低い位置から見上げるのは、権力者や壁の威圧感を出すとき。高い位置・真上は、状況の全体図（地図）。

## 5. 絵の役割
| 役割 | 割合 |
|---|---|
| 話をそのまま見せる | 55% |
| 反応 | 12% |
| 差し込み（物の寄り） | 9% |
| たとえ・ギャグ | 9% |
| **図解・地図・断面** | 9% |
| 状況説明の引き | 6% |

- **約3割のカットは説明のための絵**。図解は平らな重ね合わせにせず、3Dの世界の中に作る（地面の断面、色で温度を示す、数を数えるカウンター、物を透かして中を見せる）。
- 4組とも「抽象的な説明の一文には、その一文のための絵を1枚あてる」と報告している。

## 6. 言葉と絵の合わせ方（212か所を測った）
- **絵の変化は、その言葉の頭に合わせる**：ずれの中央値は0フレーム（25%〜75%：−2〜+3）。63%が±3フレームの中。
- 状態の変化（色が変わる・光る・数字が変わる）は言葉ちょうど。物理的なオチ（落ちる・壊れる）は3〜10フレーム遅れてよい。
- 読ませる看板や書類は、8〜9フレーム早く出してよい。
- → `timing.tsx` の `LEAD_FRAMES` は **0**（言葉ちょうど）。オチだけ `at(word, { lead: -6 })` で遅らせる。

## 7. 演技
- 表情や姿勢の変化：**10秒に約4回**（2.9〜5）。1つの表情を1.2〜2秒保つ。
- **動きを補間でつながず、ポーズを切り替える**。人物の「生きている感じ」はカメラの動きが担う。人物は歩くより、ポンと現れる・滑り込むことが多い。
- 口が動くのは、引用したセリフの時だけ（地の文のナレーション中は動かさない）。
- 漫符を必ず使う：汗（6本中6本）、怒りマーク・顔が赤くなる、湯気、Zzz、目が丸くなる。

## 8. 文字
- 字幕は1〜3語、白い太字に黒ふち、画面の高さ70%、1語ずつ切り替え（24本すべて同じ）。
- **それ以外の文字は、すべて3Dの世界の中の物にする**：看板・新聞・書類・画面・カウンター・ラベル。1本に3〜9個。大事な書類や看板は最初の7秒で見せ、最後にもう一度出す（6本中2本）。

## 9. 始まりと終わり
- **0.00秒から声が始まり、1フレーム目からカメラが動いている**（24本すべて）。1フレーム目には主人公と謎の物が映っている。
- 1.5秒以内に大きな動き、2〜3秒で最初の切り替え。
- 終わりはオチの絵（またはつかみの絵の再現）。最後の言葉の0.2〜1秒後に終わるものと、オチの絵を約1.7〜3.6秒見せるものがある。**エンドカード・暗転・フェードはない**。
- 話の転換点で光（時間帯・色）を変える（6本中4本が夜を通る）。
